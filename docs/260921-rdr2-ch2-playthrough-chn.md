### 滚轮闭锁步枪刷枪步骤 Rolling Block Rifle Glitch Steps

1. 和 Hosea 完成传奇灰熊狩猎，跟着他回营地
2. 不要进入营地——等 Hosea 下马 Silver Dollar 并结束对话
3. 骑自己的马靠近 Silver Dollar，跳上去
4. 把 Silver Dollar 骑到远离营地的地方，让它走不回去
5. 炸死 Silver Dollar，让它掉落 Rolling Block Rifle

注意：你需要这把步枪来完成一次 660 英尺的长瞄击杀

### 奇异雕像谜题 Strange Statues Puzzle

**位置：** Donner Falls 以东的洞穴，地图上 AMBARINO 的 “I” 正下方。

**线索（可选）：** Window Rock 的奇异画作（Fort Wallace 西北）。

**解法：**
1. 进洞，数每座雕像（共 7 座）的手指（缺一条手臂的雕像算作 7——手臂就躺在附近地上）
2. 按下手指数为质数的雕像正面按钮：**2, 3, 5, 7**
3. Harpy 雕像打开 → 拿走 3 根金条
4. 重置：按任意雕像背面的按钮

## 商店后室抢劫 Store Backroom Robberies

收到的提示：Strawberry 有些店不合法——留意可疑活动。

共有 4 家后室生意（杂货店、枪械店、医生诊所）。抢劫方式相同（PC 键盘）：确认提示后进店，用武器瞄准店主（**鼠标右键**），“Rob Back Room”（抢后室）选项出现——要靠近并避开视线。**重要：只有在你“知晓”这门非法生意之后，该选项才会出现**——透过被遮住的后窗，观察警员从后门收受贿赂 / 敲后门，或从 NPC（比如营地的 Tilly）/ 被放走的囚犯那里得到提示。

- ~~**Rhodes 枪械店**~~ - 楼梯底部对面的武器柜里有 Lancaster Repeater。见“武器策略”
- ~~**Strawberry 杂货店**~~ - 透过走道下方的地下室窗户偷看即可开启（“你现在可以抢这家副业了”）；地下室有 ~\$50 现金 + 物资。不引人注意就没有通缉等级——店主没法报警（他的生意本身非法）。离开时别在有人看着的情况下搜刮货架
- **Valentine 医生诊所** - Schofield Revolver + 现金 + 上锁的保险箱。总会惊动警察（警长办公室就在隔壁）：抢收银台，让他打开后室，用死眼解决里面的 O'Driscoll 帮，拿走 Schofield + 现金，然后跑。最低赏金约 ~$5。
- **Saint Denis 枪械店** - 店后花园里有高风险秘密

## 草药收集挑战 Herbal Collection Challenge

**Herbalist 2：采摘并吃掉 4 种浆果**（奖励：$5，生命经验）

必须把 4 种浆果各采摘并吃掉一个。这是游戏里仅有的 4 种。

**重要：必须直接在灌木丛上选“Eat”（吃）选项。** 摘下来再从背包里吃不算数。

- ~~Red Raspberry~~（已吃）——最常见，几乎到处都有（平原，例如 Scarlett Meadows）；Valentine 以西的田野也有。The Heartlands 大部分地方
- **Wintergreen Berry** ——最难找：灌木矮小、低矮（红浆果），被叶子遮住。用鹰眼。可靠地点：
  - **Cumberland Forest（东端）**：地图上 Cumberland Forest 的 “T” 稍北，开阔林地上——**在此确认找到一对**（一个在 “T” 正北，另一个紧挨着它，在地图浆果图标附近）
  - **Big Valley（最西侧小路）**：地图上 “Big Valley” 的 “B” 以西——主路以西两棵倒树交汇处（就在美洲狮刷新点附近），再往北主路旁的小空地
  - **Owanjila 湖 NNW**：从 Owanjila 沿路向北，在路与河分开处从左侧岔出去（美洲狮/灰熊地盘——备好武器）
  - **New Hanover/Ambarino 东北**：Annesburg 以北 Manito Glade 后面（隐士陌生人地点），靠近传奇驼鹿刷新点（Brandywine Drop），Doverhill 附近
  - 据说也在传奇熊地点 O'Creagh's Run 附近（Grizzlies East）
