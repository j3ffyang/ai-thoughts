*最后更新：2026-06*

---

## 背景：为何切换？

### 主要目标

寻找一款 **通用书签应用**，支持 **PC（Windows/macOS）、移动端（iOS/Android）以及 Linux**，且所有平台都具备功能一致性（提供相同核心功能和用户体验）。


Raindrop 是唯一原生支持这三个平台的应用。


### 触发点：Pocket 关闭

长期使用 **[Firefox Pocket](https://getpocket.com/) **作为稍后阅读和标签管理工具，直到 Mozilla 在约 2-3 年前关闭服务。迫使我迁移到一个能够：

- 跨平台工作（PC + 移动 + Linux）
- **基于标签的管理**：允许同一链接保存多个标签，支持通过标签搜索和过滤
- 不依赖任何特定浏览器厂商


### 以前使用的工具与痛点

| 工具 | 角色 | 费用 | 平台支持 | 痛点 |
|------|------|------|----------|--------|
| **[Firefox Pocket](https://getpocket.com/)** | 稍后阅读 + 标签 | 免费 | Windows/macOS/iOS/Android | Mozilla 关闭；无 Linux 桌面应用 |
| **[Feedly](https://feedly.com/)** | RSS 聚合器 | 免费/付费 | Windows/macOS/iOS/Android | 无长期保存与搜索，内容会过期 |
| **[Bit.ly](https://bitly.com/)** | 链接缩短 | 免费/付费 | 网站，浏览器扩展 | 无组织，无法捕获内容 |
| **浏览器书签** | 临时保存 | 免费 | 所有浏览器、桌面端 | 结构扁平，无标签，无全文搜索 |
| **[Pinboard](https://pinboard.in/)** | 书签管理 | 付费（11美元/年 + 25美元归档费） | 网站，iOS（非官方），无 Linux 支持 | 无官方移动/Linux 应用 |
| **[Wallabag](https://www.wallabag.org/)** | 自托管稍后阅读 | 免费/付费（托管费用） | 跨平台（网站，移动应用） | 自托管负担，无原生 Linux 桌面 |

## Raindrop — 核心功能

- **集合**（支持嵌套）— 替代 [Feedly](https://feedly.com/) 的板块与浏览器文件夹
- **标签** — 支持跨集合过滤
- **全文搜索** — 包含图片和 PDF 的 OCR
- **浏览器扩展** — 一键保存，高亮，截图
- **导入/导出** — Markdown，JSON，HTML 格式支持
- **移动应用** — 离线阅读及快速捕获

---

## 用户体验与易用性

- UI 简洁、响应迅速，并且跨平台一致。
- 应用性能总体流畅，设备间同步快速。
- 在大集合或批量操作时偶尔有轻微延迟。
- 移动端支持离线阅读，但部分功能在小屏幕上体验稍弱。
- 浏览器扩展与保存和注释功能整合良好。
- 总体用户反馈显示跨平台体验强劲，少量可改进空间。

## 开源与透明度

- Raindrop.io 是开源的，客户端应用的源代码公开托管于 GitHub。
- 包含 Web、浏览器扩展、iOS、Android 和桌面应用。
- 这种透明度支持社区贡献、安全审计，增加软件信任度。
- GitHub 链接：https://github.com/raindropio

## 安全与隐私（截至 2026-06）

- Raindrop.io 的数据存储于德国法兰克福的 AWS 服务器，数据在多个数据中心保持三份备份。
- 所有连接均通过 HTTPS 加密，使用 RSA 2048 位密钥，支持前向保密和 SHA-256 摘要，Qualys SSL 评级为“A”。
- 数据持续备份，支持恢复至最近一年的任意时间点。
- 集合和文件默认私密，文件分享链接临时有效，仅 10 分钟后过期。
- 支持双因素认证（2FA）以增强登录安全。
- 采用自主管理，专注付费订阅营收，无投资人支持，无广告，无数据挖掘和销售行为。
- 所有客户端应用均开源，代码公开透明，支持社区检查和贡献。
- 持续符合 SOC 2 Type II 合规标准，保障安全性。
- 详尽的隐私政策和服务条款可查阅 Raindrop 官方网站。
