# Death - Video Generation Skill

## Objective

This is a custom SKILL.md, complying with Hermes Agent and OpenClaw, to generate a 5-minute documentary video exploring Mexican culture's unique approach to death. The video uses OpenRouter API with Seedance 2.0 (bytedance/seedance-2.0) for AI-generated footage, incorporating 10 personal photographs as image-to-video starting frames. ## OpenRouter API Workflow

### Phase 1: Project Setup

1. **Get OpenRouter API Key**
   - Sign up at openrouter.ai
   - Generate API key
   - Set environment variable: `export OPENROUTER_API_KEY=your_key_here`

2. **Verify Seedance 2.0 Availability**
   ```bash
   curl https://openrouter.ai/api/v1/videos/models \
     -H "Authorization: Bearer $OPENROUTER_API_KEY"
   ```
   - Confirm `bytedance/seedance-2.0` is available
   - Check supported resolutions, durations, and features

3. **Prepare Assets**
   - Organize 10 photos in `assets/photos/` directory
   - Ensure photos are JPG/PNG, minimum 720p resolution
   - Name files descriptively: `section1_cemetery.jpg`, `section2_cityscape.jpg`, etc.

### Phase 2: Generate Clips via API

**API Endpoint:**
```
POST https://openrouter.ai/api/v1/videos
```

**Request Headers:**
```json
{
  "Authorization": "Bearer $OPENROUTER_API_KEY",
  "Content-Type": "application/json"
}
```

**Image-to-Video Request Template:**
```json
{
  "model": "bytedance/seedance-2.0",
  "prompt": "YOUR_PROMPT_HERE",
  "duration": 10,
  "resolution": "720p",
  "aspect_ratio": "16:9",
  "frame_images": [
    {
      "type": "image_url",
      "image_url": {
        "url": "data:image/jpeg;base64,/9j/4AAQ..."
      },
      "frame_type": "first_frame"
    }
  ]
}
```

**Text-to-Video Request Template:**
```json
{
  "model": "bytedance/seedance-2.0",
  "prompt": "YOUR_PROMPT_HERE",
  "duration": 10,
  "resolution": "720p",
  "aspect_ratio": "16:9"
}
```

**Generation Process:**
```python
import requests
import time
import os
import base64

OPENROUTER_API_KEY = os.environ.get("OPENROUTER_API_KEY")

def image_to_data_uri(path):
    """Encode an image file as a base64 data URI."""
    with open(path, "rb") as f:
        data = f.read()
    ext = os.path.splitext(path)[1].lower()
    mime = "image/png" if ext == ".png" else "image/jpeg"
    b64 = base64.b64encode(data).decode("utf-8")
    return f"data:{mime};base64,{b64}"

def generate_video(prompt, photo_path=None, duration=10):
    """Generate a video clip using Seedance 2.0 via OpenRouter."""
    
    payload = {
        "model": "bytedance/seedance-2.0",
        "prompt": prompt,
        "duration": duration,
        "resolution": "720p",
        "aspect_ratio": "16:9"
    }
    
    # Add image-to-video if photo provided
    if photo_path:
        payload["frame_images"] = [
            {
                "type": "image_url",
                "image_url": {"url": image_to_data_uri(photo_path)},
                "frame_type": "first_frame"
            }
        ]
    
    # Submit generation job
    response = requests.post(
        "https://openrouter.ai/api/v1/videos",
        headers={
            "Authorization": f"Bearer {OPENROUTER_API_KEY}",
            "Content-Type": "application/json"
        },
        json=payload
    )
    
    job = response.json()
    job_id = job["id"]
    polling_url = job["polling_url"]
    
    # Poll for completion
    while True:
        status_response = requests.get(
            polling_url,
            headers={"Authorization": f"Bearer {OPENROUTER_API_KEY}"}
        )
        status = status_response.json()
        
        if status["status"] == "completed":
            return status["video_url"]
        elif status["status"] == "failed":
            raise Exception(f"Generation failed: {status.get('error')}")
        
        time.sleep(5)  # Wait 5 seconds before polling again
```

### Phase 4: Download and Organize

```python
def download_video(url, filename):
    """Download generated video to local directory."""
    response = requests.get(url)
    with open(f"output/clips/{filename}", "wb") as f:
        f.write(response.content)

# Download all clips
for i, clip_url in enumerate(section1_clips):
    download_video(clip_url, f"section1_clip_{i+1:02d}.mp4")
```

## Troubleshooting

### Common Issues

| Issue | Solution |
|-------|----------|
| Character drift between clips | Use Image-to-Video with same starting frame, repeat full prompt verbatim |
| Inconsistent lighting | Add specific lighting description to prompt, use same seed parameter |
| Audio sync issues | Re-sync voiceover manually, adjust clip timing |
| Visual artifacts | Regenerate clip with more detailed prompt, try different seed |
| Music transitions jarring | Add cross-fades, adjust music timing, use volume automation |
| Text overlay timing off | Adjust in/out points, verify subtitle sync with voiceover |
| API rate limiting | Implement exponential backoff, space requests 5-10 seconds apart |
| Image upload errors | Verify file format (JPG/PNG), check file size < 20MB, ensure base64 encoding succeeds |
| Generation timeout | Poll status every 5 seconds, timeout after 5 minutes, retry if needed |
| Inconsistent style across clips | Use same seed value for all clips in a section, maintain consistent prompt structure |

### OpenRouter API Specific Issues

| Issue | Solution |
|-------|----------|
| Authentication error | Verify API key is set correctly in environment variable |
| Model not found | Confirm using exact model ID: `bytedance/seedance-2.0` |
| Invalid duration | Seedance 2.0 supports 4-15 seconds per clip |
| Resolution not supported | Use 720p or 480p (native resolutions for Seedance 2.0) |
| Polling timeout | Increase timeout threshold, check job status manually |

## Appendix: Prompt Templates

### Image-to-Video Prompt Structure

```
[Camera movement], [subject action], [environment details], 
[mood/atmosphere], [lighting], [sound description], 
[style descriptor]
```

### Example Prompts

**Cemetery Scene:**
```
Slow dolly forward through a Mexican cemetery at dusk, 
marigold petals floating in the air, candles flickering 
on grave sites, warm golden hour lighting, ambient sounds 
of distant bells and crickets, cinematic documentary style
```

**Market Scene:**
```
Tracking shot through bustling Mexican market, vendors 
selling colorful produce, natural movement of people 
shopping, vibrant atmosphere, warm sunlight, authentic 
street sounds, documentary style
```

**Church Interior:**
```
Slow pan across cathedral interior, stained glass windows 
casting colorful light beams, reverent atmosphere, 
architectural grandeur, warm candlelight, ambient reverb, 
cinematic documentary style
```

### Prompt Writing Tips

1. **Be specific**: Include exact camera movements (dolly, pan, tilt)
2. **Describe lighting**: Golden hour, candlelight, natural light
3. **Include atmosphere**: Warm, somber, celebratory, contemplative
4. **Add sound cues**: Bells, crickets, market chatter, music
5. **Specify style**: Cinematic documentary, artistic, intimate
6. **Avoid ambiguity**: Don't use vague terms like "nice" or "good"
