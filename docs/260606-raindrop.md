# Raindrop.io — Personal Evaluation

## Disclaimer
- No affiliation with Raindrop
- Free plan user only — no Pro experience

## Background: Why Switch?

### Primary Goal
Find a **universal bookmark app** available on **PC (Windows/macOS), Mobile (iOS/Android), and Linux** — all with full feature parity.

Raindrop is the only one meeting all three platforms natively.

### Trigger: Pocket Sunset
Used **Firefox Pocket for years** until Mozilla sunset it (~2-3 years ago). This forced migration to a service that:
- Works everywhere (PC + Mobile + Linux)
- **Tag-based organization**: save one URL with multiple tags → search/filter by tag
- Not tied to a browser vendor

### Previous Tools & Pain Points
| Tool | Role | Pain Point |
|------|------|------------|
| **Firefox Pocket** | Read-later + tags | Sunset by Mozilla; no Linux desktop app |
| **Feedly** | RSS aggregation | No long-term save/search; items expire |
| **Bit.ly** | Link shortening | No organization, no content capture |
| **Browser bookmarks** | Ad-hoc saving | Flat, no tags, no full-text search |
| **Pinboard** | Bookmarking | No official mobile/Linux apps |
| **Wallabag** | Self-hosted read-later | Self-host burden, no native Linux desktop |

## Raindrop — Core Features Used
- **Collections** (nested) — replace Feedly boards + browser folders
- **Tags** — cross-collection filtering
- **Full-text search** — including OCR on images/PDFs
- **Browser extension** — one-click save, highlight, screenshot
- **Import/Export** — markdown, JSON, HTML
- **Mobile app** — offline read, quick capture

## Security & Privacy (verified 2026-06)
- Bootstrapped, no investors — revenue = Pro only
- No ads, no data mining, no selling
- SOC 2 Type II, AWS Frankfurt, 2FA
- Private by default; share links expire in 10 min

## Verdict
- Replaces Feedly "save for later" + Bit.ly + bookmarks
- Free tier sufficient for my case
- Pro worth it if: nested collections, OCR, unlimited search needed
