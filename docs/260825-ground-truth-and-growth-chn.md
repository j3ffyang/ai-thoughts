# Ground Truth and Growth — 真相与成长

**原文：** [260825-ground-truth-and-growth.md](260825-ground-truth-and-growth.md)

![Ground Truth and Growth — visual summary](../imgs/260825-ground-truth-growth.png)

我需要和 AI 智能体 (AI agents) 一起工作——写技术文档、用 Python 和 shell 写代码、产出 YAML 和 markdown，大部分用英文，偶尔用中文，还要审查和整理我十多个 git 仓库和项目。这就是工作量。问题是要选哪个智能体 (agent)。我选了 **OpenCode**。

OpenCode 负责写作和编码化 (codifying)、生成图片、检查措辞，还做那些过去一下午都在做的繁琐格式工作。但真正的技能 (skill) 不是学会这个工具——而是学会**节奏 (the pace)**。AI 工作很快，而我是个急性子，所以得学会驾驭它，不让自己跑太快。不太快，也不太慢。找到**节奏 (the rhythm)**，让智能体跟得上，但我依然掌控全局。这个平衡最终证明是最难的部分，也是最重要的。

和 AI 一起工作让我学到的东西出乎意料。我学会了**耐心 (patience)**——不是从自助书里学的，而是看着机器精确执行我要求的事情，然后意识到我和它之间的差距几乎总是我自己的错。智能体很精确。它理解指令的方式非常字面，迫使你必须说清楚。而在这个被迫的**清晰 (clarity)** 中，我进步了。我学会了 Git 自动化 (automation) 和 GitHub Actions——这些我以为自己已经掌握但实际上没有的东西。和智能体一起工作暴露了我理解中的空白，然后一个命令一个命令地填补了它们。

更深层的礼物是学会了 Git 本身，不只是表面的命令。我是个重度 Linux 用户，几十年了，大部分工作都在终端 (terminal) 里——那是原汁原味的 Linux 体验，是我一直想要的开源生活。终端给了我 GUI 永远给不了的东西：**真相 (ground truth)**。每个命令都可见，每个错误都诚实，每个输出都是原始的。终端告诉我数据实际去了哪里，落在哪个数据中心，系统实际做了什么。没有客气的包装隐藏真相。这是我所知道的最诚实的对话——我和机器之间，没有中间人。

在那个诚实的交流中，有些东西改变了。和智能体一起工作提升了我的写作——不只是技术文档，而是文学。描述、论证、用证据说服。让智能体理解我意思的这个纪律 (discipline) 迫使我写得更好。而且这有一种冥想的品质 (meditative quality)：你平静地说，耐心地听，迭代 (iterate)。这不只是生产力。这是**一种练习 (a practice)**。

工作流 (workflow) 通常是这样的：头脑风暴 (brainstorm) 想法、列出要点、手动润色 (polish by hand)、和智能体一起润色 (polish with the agent)、一起审查和分析 (review and analyze)、来回更新和修改 (update and change)。它不是线性的。它是**一个循环 (a loop)**，而这个循环才是真正工作发生的地方。不知怎么的，它还挺有趣的。

```
    头脑风暴 (brainstorm)
         │
         ▼
    列出要点 (list bullets)
         │
         ▼
    手动润色 (polish by hand) ◄──────────┐
         │                               │
         ▼                               │
    和智能体润色 (polish with agent)     │
         │                               │
         ▼                               │
    审查分析 (review & analyze) ──► 更新修改 (update & change)
```
