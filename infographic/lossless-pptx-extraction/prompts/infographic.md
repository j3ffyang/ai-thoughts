### The pipeline (central subject)

### Requirement
The governing constraint is that everything is kept verbatim and nothing is summarized; the harder goal is proving that nothing was lost, not the conversion itself.

### Three classes
Three equal panels sort a deck's contents: what is retained (text, tables, notes, content images), what is omitted by design (layout backgrounds, logos, inherited placeholder text), and what cannot be represented and so is surfaced in a visible note rather than embedded.

### Audit (the product)
A five-point verification is the deliverable: it compares marker counts against the source's slide total, accounts for every embedded media blob, confirms each image reference resolves to a file on disk, checks that all source text appears in the output, and logs each unextractable note. The first four are hard gates; the fifth is only reported. Nothing may disappear without a stated reason.

### Bugs
Five defects that only review caught: broken image references, a date that changed on every run, a wrong format-signature check, a substring-based comparison limitation, and a dormant crash path.

### Hosting decision
Remote CI was rejected because it sees only what git tracks and the source decks are large confidential binaries; automation therefore stays on the machine, where the price of having no remote is a backup practice.
