# OpenCode + Git: The Underrated Duo

## Overview
A 9-step thought-flow → workflow loop that turns an AI agent + git into a small team's worth of automation, built over a single weekend.

## Learning Objectives
The viewer will understand:
1. The division of labor: human = intent, agent = expertise, git = safety net
2. The 9-step loop that makes the combination work
3. What you actually need to know (very little) to unlock it
