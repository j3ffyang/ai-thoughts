## Main Topic
How a 15-year git user produced more automation in two days with an AI agent (OpenCode) than in most of those years — by dividing labor between human intent and agent expertise, connected by a 9-step thought-flow loop.

## Learning Objectives
After viewing this infographic, the viewer should understand:
1. The division of labor: human holds intent, agent holds expertise, git is the safety net
2. The 9-step thought-flow → workflow loop that makes the combination work
3. What you actually need to know (very little) to unlock the whole system
