# Happy Birthday Linux — From AIX to Arch

## Overview
A 35-year personal journey with Linux, told as a winding road from discovering AIX at IBM to a fully-Arch household. Whimsical watercolor memoir style.

## Learning Objectives
The viewer will understand:
1. One person's 35-year arc: AIX → got hacked → security habit → distro hopping → Arch → all machines Linux.
2. That being hacked turned encryption/ssh/firewalls into a permanent habit that paid off in the cloud era.
3. The recurring threads: minimalism, no bloatware, open-source, one unified OS.
