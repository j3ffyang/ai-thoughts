## Main Topic
A practitioner's case against persona-based agent instructions, arguing that the most valuable content in AGENTS.md files is operational law — rules earned through specific incidents where things went wrong.

## Learning Objectives
After viewing this infographic, the viewer should understand:
1. The difference between persona instructions (what an agent is) and constitutional rules (what an agent may do)
2. Real-world failure modes that produce durable agent config rules
3. What makes a rule survive — four traits: traceable to incident, single owner, verifiable, cheap to obey

## Target Audience
- **Knowledge Level**: Intermediate — developers already using AI coding agents with config files
- **Context**: Evaluating or improving their own AGENTS.md / CLAUDE.md / .cursorrules setup
- **Expectations**: Practical lessons from real failures, not theoretical best practices

## Content Type Analysis
- **Data Structure**: Sequential narrative (3 named scars + 5 compressed observations) converging to a thesis
- **Key Relationships**: Each scar → rule; rules accumulate → constitution; constitution outlives the model
- **Visual Opportunities**: Incident → damage → rule as visual flow; persona vs constitution as binary comparison; the four surviving traits as a checklist
